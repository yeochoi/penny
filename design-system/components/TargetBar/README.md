# Target bar

Shows how much of this month's target is used and what is left.

- A `size-line` bar, `gold-line` on `track`, full width under the change line.
- Left in `caption` 500 says €141 left for 12 days. Right in `muted` says Target €1,425.
- Over target the fill and the left text turn `coral-text` and read €40 over.
- Before the first full month it reads Your first target starts in December.
