# Category row

One category on Month, with what it cost this month.

- `body` name and amount, a `size-line` `gold-line` bar under them, scaled to the biggest category.
- Rows sit in one `surface` card with `radius-card` and `card-pad`, no dividers.
- The top four show. A more link in `gold-text` shows the rest.
- Tap a row to see its entries for the month.
